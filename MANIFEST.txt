================================================================================
                       BACKEND (Node.js + Express)
================================================================================

server/
├── index.js                        # Express server setup
├── processor.js                    # Main processing pipeline
├── websocket.js                    # WebSocket handlers for real-time updates
├── services/
│   ├── transcription.js            # Audio transcription (Whisper/OpenAI)
│   ├── ai-analyzer.js              # AI moment detection (Claude/GPT)
│   └── clip-extractor.js           # FFmpeg clip extraction and formatting
└── utils/
    ├── ffmpeg.js                   # FFmpeg wrappers (encode, analyze)
    ├── downloader.js               # YouTube and URL downloading
    └── llm-client.js               # LLM API abstraction

Processing Pipeline:
1. Download video (yt-dlp or FFmpeg)
2. Transcribe audio (Whisper or OpenAI)
3. Analyze transcript with AI (Claude or GPT)
4. Extract detected moments as clips (FFmpeg)
5. Export to multiple formats
6. Generate captions and apply effects

APIs:
- POST /api/upload - File upload
- POST /api/download-url - YouTube/URL download
- GET /api/health - Health check
- WS /ws/process/{id} - Processing progress
- WS /ws/export - Export progress

================================================================================
                      PERFORMANCE METRICS
================================================================================

Processing Speed:
  - 1-min video: 2-3 minutes total
  - 5-min video: 5-7 minutes total
  - 10-min video: 8-12 minutes total

Export Speed:
  - Per format: 30-60 seconds per clip
  - All 5 formats: ~3-5 minutes per clip

Resource Usage:
  - Memory (idle): ~100MB
  - Memory (processing): ~500MB-2GB
  - Disk: ~50% of video size

Scalability:
  - Default: 2 concurrent jobs
  - Configurable: Up to 10+
  - Queue: Unlimited
