================================================================================
                          TECHNOLOGY STACK
================================================================================

Frontend
  • Svelte 4          - Lightweight reactive UI framework
  • Vite              - Ultra-fast build tool with HMR
  • Tailwind CSS      - Utility-first styling
  • TypeScript        - Type safety for JavaScript

Backend
  • Node.js           - JavaScript runtime
  • Express.js        - Web server framework
  • WebSocket (ws)    - Real-time bidirectional communication
  • Multer            - File upload handling

Video Processing
  • FFmpeg            - Video encoding/transcoding
  • FFprobe           - Metadata extraction
  • yt-dlp            - YouTube downloader

AI & Transcription
  • Claude (Anthropic)    - Moment detection
  • GPT-4 (OpenAI)        - Moment detection
  • Whisper (OpenAI)      - Audio transcription
  • Ollama (local)        - Alternative to Whisper

Storage & Database
  • Node.js fs        - File system
  • SQLite (optional) - Metadata storage
  • Qdrant (optional) - Vector search for clips
